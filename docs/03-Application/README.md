## English

Product Media exposes provider-neutral storage, image-processing, and Department-segment ports. Task 3.14.8 will add orchestration; this foundation does not create roots or integrate Smart Save.

Application coordinates use cases between interfaces, Domain policies, and repositories without owning business rules. See [Product use cases](Product-Use-Cases.md).
