## English

Product media storage keys, roots, and slots are immutable Catalog concepts independent from Product business state; see [ADR-012](../01-Architecture/ADR/ADR-012-Product-Media-Root-Registry-and-Local-Storage-Foundation.md).

This section defines business language, invariants, policies, and the [capability map](Business-Capability-Map.md), independent from UI and persistence.
